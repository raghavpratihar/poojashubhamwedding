# Pooja weds Shubham

Wedding invitation website from the bride's family (Yadav family) — Friday, 27th November 2026, Girraj Sharma Farm House, Faridabad.

## Editing content

All names, dates, events, venue and contact details are in `src/data/wedding.js`. Event images are in `public/images/`.

## Develop

```sh
npm install
npm run dev
```

## Deploy (GitHub Pages)

```sh
git add -A && git commit -m "Update invitation"
git push
npm run deploy
```

GitHub Pages must be set to deploy from the `gh-pages` branch, `/ (root)`.
